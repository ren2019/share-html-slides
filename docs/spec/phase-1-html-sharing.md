# 阶段 1：HTML 发布与微信传看

状态：ready-for-agent。产品范围与测试边界已确认，GitHub Issues 配置已获用户批准。可进入开发拆解；未启动实现或部署。

## Problem Statement

发布者已拥有 HTML 幻灯片或阅读长网页，但不了解关联图片、脚本和其他 HTML 文件，也不希望部署网站。读者需要在国内手机、尤其微信里随手浏览或边听边看，不应为阅读或转发注册账号。

## Solution

提供电脑端材料库与装订流程：登录上传已有 HTML，发现关联资源并引导补齐，预览后发布。关联 HTML 也独立成为材料。读者通过稳定链接匿名阅读，复制可修改的固定模板文字及链接继续分享。同名上传自动更新，支持独立停止、恢复、删除和下载控制。

本规格是新产品的范围，不是原站功能清单。HTML 制作者负责内容与手机适配；系统负责正确发布和交付。阶段 1 不依赖微信富卡片成功。

## User Stories

以下沿用已确认的 US 编号，用子项补全可验收行为，不扩展产品范围。

1. **US-01 登录与归属**：作为发布者，我希望登录后访问自己的材料库，以便跨次使用和管理已有内容。其他账号不能管理我的材料，读者无需登录。
2. **US-02 上传**：作为发布者，我希望选择现成的 HTML 幻灯片或长网页，以便无需部署即可发布。
3. **US-03a 发现引用**：作为不熟悉文件依赖的发布者，我希望看到所选 HTML 缺少哪些关联文件，以便避免漏传。
4. **US-03b 补齐资源**：作为发布者，我希望选择文件所在目录由系统匹配资源，以便不必阅读和修改代码。
5. **US-03c 外部资源**：作为发布者，我希望可取得的外部静态资源随内容保存，以便减少阅读对原来源的依赖；失败项必须明确展示。
6. **US-04 独立关联材料**：作为发布者，我希望关联 HTML 也进入材料库并有独立链接，以便分别分享和管理；普通链接与嵌入均应可用。
7. **US-05 预览与不完整发布**：作为发布者，我希望预览并在有缺失项时明确选择仍然发布，以便自己判断内容是否可用。
8. **US-06 材料管理**：作为发布者，我希望在材料库找到内容及发布状态，以便打开、分享和执行已有管理操作。
9. **US-07a 匿名阅读**：作为读者，我希望在手机微信直接打开正文，以便随手浏览或跟随讲解阅读。
10. **US-07b 关联阅读**：作为读者，我希望普通关联链接和嵌入页面均可阅读，以便完整理解内容；某关联不可用不应阻断其余正文。
11. **US-08 固定模板分享**：作为任意读者，我希望免登录复制带标题和链接的文字并按需修改，以便继续转发且不依赖 LLM。
12. **US-09a 自动更新**：作为发布者，我希望再次上传同名主文件自动更新原材料，以便已经发送的链接继续使用。
13. **US-09b 失败可恢复**：作为发布者，我希望失败时收到明确提示并可重试，以便完成发布；更新失败不应破坏已发布旧版。
14. **US-10a 停止分享**：作为发布者，我希望独立停止一份材料，以便其原链接暂时不能阅读，且不影响其他独立材料。
15. **US-10b 恢复分享**：作为发布者，我希望恢复原链接，以便继续使用；停止期间上传新版不应自动恢复公开。
16. **US-11 永久删除**：作为发布者，我希望永久删除不需要的材料，以便终止它的分享；与可恢复的停止操作分开。
17. **US-12a 下载**：作为读者，我希望在允许时取得尽量完整的文件包，以便留存；未包含项明确说明。
18. **US-12b 下载控制**：作为发布者，我希望关闭下载入口，以便控制平台提供的下载能力；关联材料不应通过其他材料的下载包绕过该设置。

## Implementation Decisions

### 已确认的行为契约

- 身份边界：上传与管理要求登录；已发布材料的阅读与分享不要求登录。不建立组织、成员邀请或管理员体系。
- 账密注册验证可选手机短信或邮箱验证码，部署实例可二选一，不要求同时绑定手机与邮箱。验证所选联系方式后设置密码，之后账号+密码登录；找回密码重新验证同一渠道。未配置渠道不可伪装可用，且不阻断另一已配置渠道或已有账号密码登录。至少一个渠道真实走通才满足身份前置；普通用户不需要提供服务密钥。
- 内容边界：主内容为 HTML；图片、字体、样式和脚本作为静态资源处理，不因此增加独立图片或 PDF 发布产品。
- 关联 HTML：本地普通链接和 iframe 引用的 HTML 独立发布，保留引用关系，阅读时使用目标最新发布版本。关系仅服务发现与访问，不锁定管理操作，不级联停止或删除。
- 外部普通网站链接保持链接，不递归收录互联网网站；外部静态资源尽量保存。动态接口不承诺迁移。不能取得的资源统一进入缺失提示。
- 发布前预览；缺失资源默认要求补齐，用户可明确选择仍然发布。目录读取许可不等于允许上传所有无关文件。
- 同一账号内以主文件同名匹配更新，保留材料身份与链接。上传前明确显示将更新，无需用户另选更新入口。原有停止状态、下载设置不因内容更新自动重置。
- 关联材料停止或删除时，其访问显示不可用，其他正文继续提供；仅禁止下载不影响正常在线阅读。
- 更新失败保持旧版可读，成功后才切换新内容。多个独立材料分别报告结果，不要求整批回滚。已停止材料成功更新后仍不可读，直至明确恢复。
- 固定分享文案默认“给你分享《材料标题》”加阅读链接，发布者可使用昵称；匿名读者不被要求提供身份。复制前修改只影响本次文案，不修改全局材料信息。
- 下载默认允许，可关闭。包中跳过停止、删除或禁止下载的独立关联材料，明确列出未包含项。不把关闭按钮宣称为防复制，也不承诺撤销已经下载的副本。

### 本轮提出的最小交互约定

这些是落实既有故事的规格建议，不是原站实测结论；审阅可调整表现方式，无需增加功能。

| 界面 | 主要内容与动作 | 必须呈现的状态 |
|---|---|---|
| 登录入口 | 上传或管理前登录，成功进入材料库；公开阅读不经过此入口 | 未登录、登录失败可重试、已登录 |
| 材料库 | 标题、文件名、分享状态；上传、打开、复制分享文案；更多操作提供下载设置、停止/恢复、永久删除 | 空库、已发布、已停止、操作失败 |
| 上传装订 | 选择 HTML，展示每份新建/更新与关联发现，补齐文件或目录，预览，发布 | 分析中、需补齐、可发布、发布中、逐份成功/失败 |
| 阅读页 | 正文为主，轻量分享与允许时的下载入口；沿用 HTML 自身翻页、滚动与布局 | 加载、可读、材料不可用、关联局部不可用、平台加载失败可重试 |
| 分享操作 | 自动填好文案，可编辑后复制；复制失败提供可选取文字 | 成功提示或可操作的失败提示，不要求登录 |

- 停止分享和永久删除明确区分；删除确认说明不可恢复，停止后提供恢复入口。
- 不为批次引入单独管理页面；关联材料在同一装订队列中呈现为独立项，避免同一文件反复排队。
- 主文件改名视为新材料；同批多个不同文件具有同一名称时提示保留一个后再发布，不猜覆盖顺序。这是已有待定实现建议在本轮的建议取舍。
- 没有可用 HTML 标题时建议以文件名填充。无需增加摘要编辑器或首阶段封面生成服务。

### 品牌与主题（用户后续确认，纳入阶段 1）

产品名为纸飞机。默认主题松烟墨，可选沧海蓝、暮山紫、竹简青、霁空蓝。采用用户选定的经典折纸飞机、左上亮右下深的平滑渐变；默认灰黑同样无墨晕、纸纹或颗粒。主题只影响平台自身界面，不改变上传 HTML 的样式、布局与内容。保持高端、专业、冷静、简约。

**US-14 主题选择**：作为平台使用者，我希望在默认灰黑与四种可选配色之间切换，以便选择合适的界面风格而不改变阅读材料。此为用户后续明确增加的范围，不增加自定义配色编辑器。

最小实现建议：一个轻量主题选择入口，记住当前浏览器的选择，不引入跨账号同步或影响他人阅读的全局设置。具体入口在交互实现时采用最简方案。

### 最小数据和模块边界

概念模型为：账号拥有材料；材料拥有稳定分享标识、匹配文件名、标题、公开/停止状态和下载设置；材料内容版本关联主 HTML 与静态资源；材料之间记录引用。永久删除不可恢复，不能把原链接重新分配给别的内容。

建议保持一个应用，内部只有身份与材料管理、装订与资源处理、阅读与下载交付三个职责。不预设微服务或独立调度平台。存储与接口必须表达以下结果：逐份发布结果、缺失项、更新成功或失败、材料不可用、下载未包含项。具体框架、数据库、路由和登录供应商在开发准备时按部署条件选择；本规格不伪造原站内部接口。

上传 HTML 与平台账号管理隔离，不能取得平台登录能力；隔离不能以破坏所承诺的关联嵌入为代价。资源读取不能把任意外部 URL 变成访问服务器内部网络的入口。使用有限的可识别引用处理，循环引用去重终止，不运行无限爬取。数值限制是实现配置，不能把原站未实测的边界照搬为已确认产品需求。

## Testing Decisions

### 已确认的测试边界

以应用对用户暴露的完整流程为主：通过真实界面发布合成文件，用独立匿名浏览环境读取，再验证更新、停止和恢复。内部签名、解析步骤和数据库布局不是验收目标。复杂文件关系可通过装订服务的公开输入输出做少量定向测试；不为每个私有函数重复测试。

当前目录没有应用代码、既有测试框架或可复用测试接缝；原站探索是行为参考，不是新产品测试通过。尽量共用一组业务样本驱动浏览器验收和必要的文件处理测试。

### 验收矩阵

| 编号 | 对应故事 | 操作与可观察结果 |
|---|---|---|
| AT-01 | US-01、06 | 发布者登录上传，退出后原匿名链接仍可读；重登能找到材料；另一账号不能更新、停止或删除它 |
| AT-02 | US-02、05、07 | 分别发布自包含 slides 与长网页，预览和最终正文正确；手机微信未登录能阅读，布局责任仍属原 HTML |
| AT-03 | US-03、04 | 主 HTML 含图片、样式、脚本、普通关联链接与 iframe；补齐目录后关联 HTML 独立入库，单独访问及主页面引用均可用 |
| AT-04 | US-03、05 | 缺少本地资源或外部资源失败时准确列项；补齐后可继续；明确仍然发布后给出实际结果，不冒称完整 |
| AT-05 | US-04、09 | 关联材料单独更新后，主页面重新读取其最新内容；重复或循环引用不重复无限创建 |
| AT-06 | US-08 | 匿名打开、修改固定文案并复制，粘贴内容包含正确标题与链接；全局标题不变；下一位匿名读者可读 |
| AT-07 | US-09 | 同账号同名上传显示更新意图，成功保留旧链接并提供新版；失败旧版仍可读，重试不会产生重复材料 |
| AT-08 | US-09、10 | 停止材料后同名更新仍不可读；恢复后同一链接展示更新后的内容 |
| AT-09 | US-04、10、11 | 停止或删除关联材料，不阻止其他材料管理，主内容仍可读且关联位置提示不可用；永久删除不能恢复原链接 |
| AT-10 | US-12 | 允许时下载自包含文件或带资源包，核对 HTML 与资源；禁止下载后平台不交付下载包；引用的受限材料被跳过并说明 |
| AT-11 | US-05、09 | 多份材料中单份失败，逐份结果准确，已成功的保持可用；失败更新保持旧版，明确仍然发布不等同上传失败 |
| AT-12 | 全部 | 已上传 HTML 不能获得管理会话；越权操作被拒绝；平台失败有可理解提示，不泄露内部敏感信息 |

| AT-13 | US-14 | 新浏览环境默认松烟墨；四个可选主题名称准确，切换只改变平台外层配色，上传 HTML 保持原样；灰黑与彩色图标均为平滑渐变 |

真机验收覆盖真实 iOS 与 Android 微信的约定样本：文字链接入口、未登录阅读、复制文案及二次转发。记录系统和微信版本与结果，不用桌面模拟替代。若设备或部署条件暂不可用，记录待验收，不冒称通过。此处是测试计划，并非当前已执行结果。

## Out of Scope

- 复刻原站全部功能或像素外观；独立 PDF、图片发布，合集、收藏、阅读统计。
- HTML 制作、编辑、自动适配手机、自动重排、同步演示。
- LLM 生成文案、复杂依赖管理、组织体系、管理员后台。
- 保证任意脚本和动态接口可迁移，复制保护，撤销读者已存副本。
- 阶段 1 微信富卡片保证；自动向他人发微信消息。
- 本轮开发、部署、真实服务配置和凭据操作。
