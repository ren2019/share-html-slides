# 阶段 1 扩展规格：材料全文搜索与查询 CLI

## Problem Statement

发布者积累 HTML 幻灯片和长网页后，仅凭标题和文件名很难找到正文里的知识，也未必记得原文措辞。发布者还需要让脚本和 Agent 搜索材料并读取原文，但不希望学习如何生成、复制或配置 token、API key。公开分享链接不意味着允许他人发现整个个人材料库。

## Solution

在个人材料库中提供关键词与向量混合全文搜索，返回材料与命中片段。覆盖 HTML 中已有的全部静态正文，搜索、列表和正文读取统一提供服务端接口与 CLI。CLI 登录跳转部署实例的网页，用户沿用已有登录方式授权，凭据由程序管理。

发布与索引异步衔接：材料先可阅读，正文和索引后台建立；搜索只使用当前成功发布版本。向量未配置或不可用时明确降级为关键词搜索。停止分享的材料仍供本人查询，永久删除立即对查询生效。

## User Stories

以下细化已确认的 US-15、US-16，不改动阶段 1 原有故事编号。验收矩阵中的 US-15、US-16 覆盖各自全部子项。

1. **US-15a**：作为发布者，我希望按标题、文件名和正文中的准确词句搜索个人材料库，以便找到标题没有提及的正文内容。
2. **US-15b**：作为发布者，我希望用语义相关但措辞不同的查询找到材料，以便在不记得原文用词时仍能查找内容。
3. **US-15c**：作为发布者，我希望看到匹配材料、当前版本、分享状态和原文命中片段，以便判断相关性并打开正确的材料。
4. **US-15d**：作为发布者，我希望检索全部幻灯片页和长网页中已有的静态正文，以便不会只因某页当前未显示而漏掉内容。
5. **US-15e**：作为发布者，我希望搜索、列表和正文读取始终只涉及自己的材料，以便保护个人材料库的归属边界。
6. **US-15f**：作为发布者，我希望继续查询本人已停止分享或已关闭下载的材料，并看到准确状态，以便在限制对外分享后仍能使用自己的内容。
7. **US-15g**：作为发布者，我希望永久删除后立即从搜索、列表和正文读取中排除该材料，以便不因后台清理尚未完成而继续交付已删除内容。
8. **US-15h**：作为发布者，我希望关联 HTML 作为独立材料检索，以便分别找到和管理相关内容而不混淆来源。
9. **US-15i**：作为发布者，我希望发布成功后先正常分享阅读，由后台建立正文和索引，以便无需等待搜索处理才能使用已经发布的内容。
10. **US-15j**：作为发布者，我希望新版成功发布后不再收到旧版正文片段，更新发布失败时仍能查到当前版本，以便搜索结果与实际发布版本一致。
11. **US-15k**：作为发布者，我希望看清正文和索引的处理、失败与可重试状态，以便区分未完成索引和真正没有匹配内容。
12. **US-15l**：作为发布者，我希望向量未就绪或不可用时仍可用关键词搜索，并看到降级原因，以便不中断查找且理解结果覆盖范围。
13. **US-15m**：作为部署者，我希望配置自托管或云向量服务而不要求发布者提供模型密钥，以便按部署条件提供语义检索且不绑定指定云账号。
14. **US-15n**：作为部署者，我希望服务恢复或更换模型后补建向量，重建期间继续提供关键词搜索，以便恢复语义能力并避免混用不兼容的索引。
15. **US-16a**：作为发布者，我希望让 CLI 指向所用部署实例并跳转网页登录授权，以便沿用已有身份入口而不手工生成或复制 token、key。
16. **US-16b**：作为发布者，我希望在授权页核对账号和只读查询范围并可取消，以便清楚地决定是否让当前 CLI 访问个人材料。
17. **US-16c**：作为发布者，我希望浏览器无法自动打开时能手动打开授权网页完成登录，以便仍可通过网页交接而不传递登录凭据。
18. **US-16d**：作为发布者，我希望通过 CLI 搜索和分页列出本人材料，以便让自己或代我工作的脚本、Agent 复用查询能力。
19. **US-16e**：作为发布者，我希望通过 CLI 分段读取当前正文，并按命中片段的位置继续取得上下文，以便处理长材料且不把不同版本的正文拼在一起。
20. **US-16f**：作为发布者，我希望 CLI 与网页采用相同的权限、版本和检索规则，以便从任一入口得到一致的查询语义。
21. **US-16g**：作为发布者，我希望查询命令输出可解析的 JSON、稳定错误码与正确退出状态，以便让脚本区分成功、无匹配、处理未完成和失败。
22. **US-16h**：作为发布者，我希望无需交互的查询在缺少有效登录时明确返回错误和登录提示，以便避免脚本意外等待网页交互。
23. **US-16i**：作为发布者，我希望撤销授权或退出 CLI 后停止其访问，并在需要时重新网页授权，以便管理 CLI 对本人材料的只读访问。
24. **US-16j**：作为发布者，我希望由程序保存和使用凭据且不在查询结果或日志中展示密钥，以便在不接触 token 或 key 的情况下完成查询。

## Implementation Decisions

### 应用与接口边界

- 保持一个应用及同仓后台 worker。网页和 CLI 共用材料查询服务，后台负责静态正文提取与索引；CLI 不复制材料库另建索引。
- 沿用阶段 1 的账号、材料、成功发布版本、独立关联材料、分享状态和下载控制。原始 HTML 与资源存于已选文件后端；提取正文、片段与索引属于可重建派生数据。
- 沿用 PostgreSQL、Drizzle 与持久任务状态；不引入独立搜索集群、Redis 或消息队列。向量存储、中文关键词处理、模型供应商和排序算法在实施准备中选择验证，不能将未选方案写成已决定。
- CLI 网页授权复用部署实例已有身份入口，底层协议与框架接缝在身份实现中验证；不假定交互原型或认证库已提供完整授权服务。短信或邮箱验证码可作为二选一的账密注册验证渠道；CLI 不另建登录渠道，也不要求用户操作 token/key。

- 权限范围为登录发布者自己的材料库。搜索、列表和正文读取采用同一归属边界；持有其他人的公开阅读链接不因此获得其材料库查询能力。不增加全站发现或匿名读者搜索入口。
- 使用关键词与向量混合检索，返回材料与命中片段；不生成综合回答，不增加 RAG 问答。搜索覆盖正文，不能仅用标题或文件名筛选冒充全文搜索。
- 全文范围是 HTML 文件中已有的正文文字，包含全部幻灯片页，而非仅当前显示页。不运行脚本补出正文，不对图片进行 OCR，不转写音视频；图片、脚本和媒体仍按既有资源规则发布。
- 提供搜索、材料列表、正文读取三类查询接口，并通过 CLI 暴露。借鉴 remio 的 search/read 调用方式与结构化 JSON 返回，便于脚本和 Agent 使用；不因此扩展 CLI 上传、更新、停止、删除等管理操作。

### 分享状态与本人查询

- 停止分享的材料仍可由本人搜索、列出和读取正文，结果明确标为已停止；原公开链接仍不可读。仅关闭下载也不取消本人查询能力。
- 永久删除成功后，搜索、列表及正文读取立即排除该材料，不能等待后台索引清理才生效。已发出的查询在交付结果前同样检查材料是否仍存在及是否属于当前账号。
- 关联 HTML 按各自材料身份独立检索；主材料的引用不扩大可查询范围，也不把关联材料的正文复制为主材料的命中片段。循环引用不递归扩大搜索范围。

### 发布、正文与索引生命周期

- 发布成功后在后台提取正文并建立索引，不因搜索处理失败而阻止已经成功发布的内容阅读。页面与 CLI 可观察到待处理、处理中、可查询或失败状态；失败可重试，不冒称索引已就绪。
- 搜索只使用材料当前成功发布版本的正文与索引。新版发布成功后，旧版正文片段立即退出查询；新版正文尚未就绪时可以返回当前标题、文件名等元数据，但不得用旧版正文填充结果或正文读取响应。
- 新版正文与关键词索引就绪、向量尚未就绪时，先提供正文读取和关键词搜索，明确语义检索仍在处理中或不可用。混合结果只能组合同一当前版本的数据。
- 更新发布失败时，当前发布版本不变，其已有可用正文与索引继续服务。新建或重试任务完成时须重新核对当前版本与删除状态，较旧任务不能覆盖新版索引或使已删除材料重新出现。
- 搜索结果区分“没有匹配项”和“部分材料尚未可检索”；正文未提取成功时明确返回处理中或失败，不以空正文表示处理成功。没有可提取正文的 HTML 明示仅可按元数据查找。

### 向量服务与回退

- 由部署者配置向量服务，可连接自托管服务或云服务；用于索引的正文与用于检索的查询文本发送给所选服务。不强制绑定某家云账号，也不默认连接未经配置的服务。
- 发布者与 CLI 使用者无需提供模型 key。服务地址、模型与服务端密钥由部署配置管理，不进入浏览器或 CLI 的材料查询响应。
- 服务未配置、不可用或向量仍在构建时，保留已就绪正文的关键词搜索，并在页面与 JSON 返回中明确当前采用关键词检索及降级原因。故障不伪装成无匹配结果，不影响原有发布、阅读和分享。
- 服务恢复或配置后可补建向量；模型变更所需的重建期间继续采用关键词检索，不混用不兼容的旧向量与新查询向量。

### CLI 网页授权

- CLI 指向用户选择的部署实例，登录时打开该实例的网页。用户沿用该实例已配置的网页登录方式完成身份验证，再授权当前 CLI 查询自己的材料；未登录则先登录。
- 页面明确显示当前账号与只读查询权限，允许确认或取消。凭据由程序取得、保存和使用；不要求用户生成、查看、复制或粘贴 token、API key 或其他登录密钥。
- 浏览器无法自动打开时，CLI 提供可手动打开的授权网页地址，仍由网页完成授权，不退回手工传递凭据。授权结果须绑定本次 CLI 发起的请求，过期、取消、重复完成或不匹配的回调不授予会话。
- CLI 授权仅允许搜索、列表和本人正文读取；不取得上传或材料管理写权限。授权可撤销；退出当前 CLI 清除其本地凭据并使该授权失效。凭据过期且无法续期、被撤销或本地凭据失效时，引导重新网页授权。
- 查询命令不在无人处理时自动启动交互登录：需要登录时给出结构化错误与登录操作提示，由用户显式启动授权。状态信息可显示实例和账号，不打印凭据。

### 查询交付的最小约定

以下用于落实已确认的搜索、列表和正文读取能力；具体命令拼写、安装包名和 HTTP 路由由实现决定，不另增产品操作。

| 操作 | 输入与输出约定 |
|---|---|
| 搜索材料 | 输入查询文字，支持结果数量限制及继续获取后续结果；按材料返回稳定标识、当前内容版本、标题、文件名、分享状态、阅读链接和命中片段，并说明实际检索模式与未完成索引的影响。仅元数据匹配时不伪造正文片段 |
| 材料列表 | 不带查询文字即可分页列出本人材料及分享、正文处理和索引状态；包含已停止材料，排除已删除材料 |
| 读取正文 | 按材料标识读取当前版本的提取正文，使用适合脚本和 Agent 阅读的文本表示；支持分段读取，返回材料、内容版本及片段位置，明确是否还有后续内容。正文未就绪或版本已变更时给出可识别状态，不静默拼接不同版本 |

- 命中片段来自被检索的正文，位置与材料内容版本绑定，可用来继续读取对应上下文。该位置是提取正文中的位置，不假定它等于源 HTML 的页码或 DOM 位置；阅读链接继续打开原材料，不承诺改写任意 HTML 来实现逐字高亮或精确跳页。
- 关键词覆盖标题、文件名及已提取正文。正文提取保留文字的合理阅读顺序与段落边界，排除脚本、样式源码；全部幻灯片页的静态正文均在范围内。提取和索引不改变上传文件与阅读样式。
- 查询命令标准输出为结构化 JSON，沿用 remio 风格，包含成功标志，以及相应的数据或错误信息；可提供格式化显示。进度与诊断不混入 JSON，错误包含稳定错误码和可操作说明并返回非零退出码；无匹配结果是成功的空结果。
- 网页与 CLI 共用服务端查询权限、当前版本规则和检索结果契约，CLI 不自行下载整个材料库建立另一个索引。具体向量存储、模型供应商、排序算法与容量数值属于实现选型；用实际部署配置与约定样本验证，不把尚未测得的规模或延迟写成已验证承诺。

## Testing Decisions

### 测试边界与既有依据

- 沿用本轮已确认的 AT-14 至 AT-23：以发布者实际可观察的发布、查询、授权与读取流程验收，不测试私有函数、分块实现、向量表布局或内部调用次数。
- 核心测试边界是服务端材料查询能力的公开输入输出。页面和 CLI 是同一能力的两个入口，共用一组业务样本；分别验证少量真实网页交互与 CLI 进程交付，避免为每层重复一套完整测试。
- 集成覆盖身份与授权、发布后的正文/索引处理、材料查询；通过公开发布和管理操作建立更新、停止和删除场景，通过查询结果及可见状态断言结果。较旧任务晚到、失败和重试只在可控测试环境安排执行顺序，不为私有 worker 函数逐个造测试。
- 既有原型已经演示发布者认证、材料状态变化、关联阅读和失败重试，并有浏览器流程检查记录；它仅使用合成数据与内存状态，没有正式全文搜索服务、CLI 或可复用的生产查询测试边界。可复用业务场景，不能复用模拟成功作为生产证据。
- Playwright 验证页面搜索与浏览器授权；CLI 从实际进程检查标准输出 JSON、退出状态和端到端查询。少量服务公开接口集成测试覆盖难以从界面稳定安排的任务竞争。具体测试框架与生产代码一起初始化，不为本次文档发布新增产品测试代码。
- 语义召回必须连接真实向量服务，使用标题和文件名不含目标词、正文准确词句匹配、语义相关不同措辞等约定样本，记录模型与配置。故障注入可验证降级，模拟向量结果不能替代真实语义召回验收。
- 权限样本至少包含两个账号、相同查询词、已停止及已删除材料和独立关联 HTML；静态正文样本包含多页幻灯片、长网页、脚本生成文字、仅图片文字与无可提取正文。
- 测试计划不等于已执行结果。部署、真实模型、认证或微信真机条件尚未具备时明确记录待验证；容量与延迟报告使用实际环境和样本，不虚构数字承诺。原有匿名阅读、更新、停止恢复与下载回归边界继续适用。

### 验收矩阵

| 编号 | 对应故事 | 操作与可观察结果 |
|---|---|---|
| AT-14 | US-15 | 标题与文件名不含目标词的材料仍可因正文准确词句命中；另用语义相关但不含相同关键词的问法找到约定样本；返回材料与来自其正文的片段，不生成综合回答 |
| AT-15 | US-01、15、16 | 两个账号各自发布含相同查询词的材料，页面与 CLI 查询只返回本人材料；跨账号正文读取及匿名调用查询接口被拒绝；公开链接阅读仍遵守原有契约 |
| AT-16 | US-15、16 | 已写入 HTML 的其他幻灯片页文字可检索和读取；脚本运行后才产生的文字、仅存在于图片或音视频中的内容不被冒称已收录 |
| AT-17 | US-16 | 通过 CLI 完成搜索、列出材料、读取命中材料正文，返回可由 JSON 解析器读取的结构化数据；页面与 CLI 采用相同的查询权限和正文范围 |

## Out of Scope

- 全站材料发现、匿名读者搜索、跨账号查询、组织体系或管理员后台。
- RAG 生成回答；运行脚本提取正文、图片 OCR、音视频转写；独立 PDF 或图片发布。
- CLI 上传、更新、停止、删除等材料管理写操作；手工生成或粘贴 token/key 的登录方式。
- 自动改写 HTML、保证任意材料精确跳页或逐字高亮；把关联正文复制进主材料索引；抓取外部网站扩充材料库。
- 新增独立搜索集群、本地离线材料库、绑定指定云服务，或提前承诺未测得的容量和延迟。
- 本次规格发布不包含实施、自动拆票、部署或修改真实服务凭据。
