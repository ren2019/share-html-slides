# 纸飞机技术选型

2026-09-13 选型记录，含 2026-09-14 搜索扩展。2026-09-18 用户明确批准 #6 人工评审，正式实施在草稿 PR #19 中推进；选型文档不代表功能已经实现或验收通过。具体版本在工程初始化时核对并锁定。

## 前端与视觉

选择 TypeScript、React、Next.js App Router、shadcn/ui、Tailwind CSS、Lucide React。使用 pnpm 管理依赖。

沿用对标站的信息架构、主要区域关系和已实测操作顺序，只保留产品已确认范围。重新实现组件、视觉层级与文案，不使用下载的原站打包代码。上一轮 A/B/C 为探索记录，不作为正式布局基础。

shadcn/ui 用于按钮、弹窗、菜单、表单、状态提示等组件源码；按需引入并修改，不套现成后台模板。Lucide 用于操作图标，不替代已定稿的经典折纸品牌标志。使用松烟墨默认主题及四个选定主题；白底、墨色文字、细分隔、小圆角、克制阴影，渐变集中在品牌标志与少量强调区域。主题变量只作用于平台界面。

备选 Ant Design 功能丰富，但本产品没有复杂企业表单与管理后台需求；为了更自由地定制品牌而选择 shadcn/ui。这是适配判断，不以 stars 排名决定质量。

## 应用与存储

- Next.js 的 Node.js 运行时承载管理界面、身份与材料 API；一个代码库，不额外建立微服务。
- PostgreSQL 保存账号、材料、版本、引用与发布处理状态；Drizzle ORM 管理查询和迁移。原始 HTML 文件与关联资源正文不存数据库；搜索用的提取正文、片段和索引是可从原文件重建的派生数据，不受这条原文件存储约束限制。
- Better Auth 处理发布者会话与手机号／邮箱密码认证；微信网站扫码采用服务端 OAuth 适配，初始化时验证框架接缝，不假设内置微信 provider 已满足要求。
- 文件后端可选：本地持久目录、S3 兼容服务、MinIO、阿里云 OSS。S3 与 MinIO 共用 S3 适配器，endpoint、region、bucket、寻址方式可配置；OSS 使用独立原生 SDK 适配器，避免把其部分 S3 兼容视为完全等价。各后端验证上传、读取、删除、范围读取及内容类型；不强制部署 MinIO 或指定云账号。
- 使用 parse5 解析 HTML，CSS 解析器处理 url/import；浏览器发现本地依赖并匹配用户选择的目录，服务端复核并处理外部静态资源。有限静态引用扫描，不承诺发现任意运行时脚本依赖。
- 装订耗时任务使用同仓库 Node worker、PostgreSQL 持久任务状态与有限重试；进程重启不丢任务。第一阶段不引入 Redis、独立消息队列或 Kubernetes。
- Docker Compose 用于可复现自托管，应用、worker 与 PostgreSQL 为最小组成；生产反向代理提供 HTTPS。Next.js 不绑定 Vercel。

## 材料全文搜索与查询 CLI（2026-09-14 范围增补）


依据阶段 1 规格中已确认的 US-15、US-16 与 AT-14 至 AT-23，增加以下实现约束；尚未实现或连接真实向量服务。

- 网页和 CLI 共用应用内的材料查询服务，统一检查账号归属、当前成功发布版本及删除状态。已停止材料仍供本人查询，分享路由继续拒绝匿名读取。CLI 只提供查询，不把材料管理写权限一并授予。
- HTML 静态正文提取与索引沿用同仓 worker、持久任务状态及有限重试。按材料和内容版本关联派生数据；索引异步建立，任务完成前复核当前版本与存在状态，不让晚到任务覆盖新版或复活删除材料。
- 关键词检索和向量检索组成混合查询。先保证当前版本的提取正文与关键词可用，再补建向量；新版本切换后不再查询旧版正文片段。正文、关键词和向量就绪状态分别表达，接口明确返回检索模式与降级原因。
- 向量服务由部署者配置，可连接自托管或云服务；未配置和故障时降级为关键词，不影响发布与阅读。模型服务密钥只保存在服务端部署配置，发布者及 CLI 使用者无需提供，也不会从响应取得。模型更换后重建索引，不混用不兼容的向量。
- CLI 是部署实例的查询客户端，无需安装 remio 或本地复制材料库。登录跳转该实例网页，沿用其已配置身份入口，由程序完成授权结果交接和凭据保存；用户不生成或复制 token/key。自动打开网页失败时展示授权地址，仍以网页授权完成登录。
- 授权须绑定发起请求，限制为本人只读查询，可撤销并处理退出、过期与重新授权。内部凭据不出现在查询 JSON、状态输出或日志中；查询命令与交互登录分开。具体协议接缝在身份实现时验证，不假定所选身份框架已内置完整 CLI 授权流程。
- 查询命令输出结构化 JSON；列表和搜索支持分页，正文支持带版本信息的分段读取。命中定位属于提取正文，不通过注入脚本改写源 HTML 来保证精确跳页。

向量存储实现、模型供应商、中文关键词处理与排序算法在工程初始化时选择并验证。此次范围确认没有选定这些依赖，也不新增独立搜索集群或强制云账号；数值容量和延迟以真实配置的验收样本报告。

## 开源部署契约

- 标准安装可以在普通 Linux 服务器用 Docker Compose 运行，无需任何指定云账号。Compose 是默认交付方式，不是唯一运行方式；提供 Node 进程运行说明。
- PostgreSQL 是明确的基础依赖，可容器自建或连接外部服务，不绑定托管供应商。不为追求任意可替换而同时维护多种 SQL 数据库。
- 公网 URL、内容隔离 origin、端口、数据库连接、文件后端与容量限制使用配置；禁止在源码写入固定域名、地域或云资源 ID。提供无密钥的 .env.example 与持久卷、迁移、备份恢复说明。
- 发布者提供微信扫码登录，或验证后注册账密账号。账密验证可选手机短信或邮箱验证码：部署实例可以二选一，不强制短信，也不要求用户同时绑定手机和邮箱。注册验证所选手机号／邮箱后设置密码，之后使用该账号+密码登录，找回密码重新验证同一渠道。验证码仅证明该联系方式控制权，不等同实名核验。
- 微信扫码默认指电脑网站展示二维码、手机微信确认后电脑登录；不自动扩展为微信内网页 OAuth。微信浏览器内需要登录时提供已启用的手机号／邮箱密码入口，避免要求用户扫描本机二维码。匿名阅读分享不变。
- 微信扫码与账密是两条替代路径，按当前措辞不要求微信用户再次绑定手机号。手机号、邮箱与微信账户不按昵称或未验证资料自动合并；如果以后增加绑定，须证明两侧身份。
- 开源部署者按需配置微信应用凭据/回调、短信 provider/模板/签名或邮件发送服务。短信与邮箱可二选一，未配置某渠道只关闭该渠道注册和找回，不阻断另一已配置渠道；已有已验证账号仍可密码登录。未配置微信时不显示有效扫码入口。至少一种真实可用方式才能开放发布者注册；普通用户无需接触发送服务密钥。开发模拟验证码仅限显式测试环境，生产禁止。
- 短信／邮件发送与认证逻辑隔离，不绑定单一供应商。首个供应商适配在部署接入时确定，使用同一验证契约；验证码有有效期、单次消费、发送与验证频率限制，日志不记录密码、验证码和应用密钥。
- 管理站与内容源隔离是产品安全条件，并非某云供应商要求。生产使用部署者可控的 HTTPS origin，管理 Cookie 为 host-only，内容源不获得管理 Cookie/CORS 权限；本地有对应的双 origin 配置。
- 微信实际访问需要手机可达的 HTTPS 服务。公开仓库、localhost 演示与可在微信访问的部署是三种不同结果。

## HTML 交付与微信

管理会话与上传内容使用不同站点隔离，账号 Cookie 不跨域共享。公开阅读外壳通过隔离的内容源加载 HTML，不能将任意用户 HTML 注入管理页面 DOM。材料之间的普通链接和嵌入由内容交付路由解析稳定标识并检查公开状态。沙箱权限按实际样本验证，避免破坏承诺的脚本和关联阅读。

本地文件不直接挂载为公共静态目录，对象存储桶保持私有，通过交付服务检查停止/删除状态后提供内容；不暴露可永久绕过状态检查的原始公开对象地址。可变阅读入口不使用长期公共缓存，更新成功后原子切换当前版本。隔离站点和域名拓扑需要在上线前验证。

桌面管理端使用 shadcn/ui + Tailwind；公开阅读外壳使用简单 HTML/CSS 和少量客户端 JS，正文无需等待管理端组件加载。Tailwind 4 官方最低基线为 Chrome 111、Safari 16.4、Firefox 128，不能据此宣称所有微信兼容。手机端基础分享与下载界面避免依赖这些新 CSS 特性，复制失败保留手动选择文案路径。

平台字体、图标、JS/CSS 随应用部署，不依赖 Google Fonts 或海外公共 CDN。上传 HTML 的显示适配仍由其制作者负责。阶段 2 微信卡片另行验证官方接口与账号条件，不因使用 Next.js 或添加元标签而保证出现卡片。

## 微信阅读能力与回退契约

以下是实现与验收要求，尚无新产品真机通过证据。不把微信版本号或 UA 等同于唯一浏览器内核；记录真机型号、系统、微信版本、实际能力和测试日期。

| 能力 | 实现与回退 | 验收要求 |
|---|---|---|
| 匿名阅读 | 服务端输出轻量外壳和内容入口；不等待 React hydration，不要求第三方 Cookie或登录 | 从微信群文字链接打开 slides 与长网页 |
| 翻页、滚动、触摸 | 保留源 HTML 行为；平台工具条不遮挡正文，不捕获内容区滑动；基础高度和安全区有 CSS 回退 | 竖横屏、连续滚动、触摸翻页、键盘出现后可操作 |
| 复制分享文案 | HTTPS 下用户点击后尝试 Clipboard API；失败直接显示可选取的完整文字和 URL，不依赖 Web Share API | 实际粘贴到聊天，二次匿名打开；API 不可用时手动复制可完成 |
| 关联 HTML 和 iframe | 稳定路由与状态检查；验证沙箱允许的脚本、嵌套链接及内部滚动；正文不读取平台会话 | 普通链接、嵌入、返回、更新后读取，以及关联停止的局部提示 |
| 下载 | 服务端生成下载响应，不把 a[download] 或 Blob 下载当成微信保存保证；不能保存时提供复制下载链接、浏览器打开说明 | iOS/Android 分别记录直接保存或回退流程的实际结果 |
| 音视频与全屏 | 不保证自动播放；源内容需有点击播放入口。平台自身不以自动播放、全屏或弹出新窗口为必经路径 | 含媒体样本点击播放与返回；源 HTML 不支持的能力明确归因 |
| 分享卡片 | 阶段 2 按可选微信配置启用；关闭、失败或未配置不影响文字链接分享 | 单独真机验收，不以 Open Graph 标签或桌面预览替代 |

手机公开入口不复用依赖现代 CSS 的管理端组件包；基础操作用简单 DOM/CSS 与小型独立脚本实现。能力检测优先于 UA 分支。具体最低支持设备/系统范围在首轮 iOS 和 Android 微信真机结果后写入公开兼容矩阵；发布前矩阵必填，不能承诺所有历史微信版本。

宿主与内容隔离、复制、下载回退和嵌套页面构成首个兼容性验证样本。桌面 Playwright WebKit/Chromium 只用于提前发现问题，不能替代实际微信验收。

## 验证

Playwright 验证发布、匿名阅读、更新、停止恢复与分享等完整流程；Vitest 仅补充装订服务公开输入输出的复杂关系样本。沿用规格 AT-01 至 AT-23，增加页面与 CLI 查询、索引生命周期及浏览器授权的端到端验收，并进行 iOS/Android 微信真机验收。语义召回使用真实向量服务验证；原型点击成功不代表生产验收。

前端原型评审 #6 已于 2026-09-18 获用户明确通过。正式实现沿用已确认的材料库与上传布局、shadcn/ui 和 Lucide，按实施票依赖接入真实服务；原型内存状态不作为生产实现。

## 本轮新增验收

- 四种存储选项按各自真实后端运行同一发布/读取/停止/删除样本；无真实服务凭据者标记待验证。
- 手机短信与邮箱验证码分别覆盖正确、错误、过期、重复使用、重发限流；未完成所选渠道验证不能取得发布者能力；账号密码登录与密码找回。仅配置邮箱时不依赖短信，仅配置短信时不依赖邮箱；真实接通其中一种即可满足 #8 的渠道前置。

- 未配置的身份方式正确隐藏或说明不可用，另一方式及匿名阅读仍正常。
